# 포팅 참고 사항

- **부팅과 RAM**. CRZ GP는 1 GiB 보드입니다. U-Boot에서 `init_boot`를 포함한 Android 부팅 이미지와 보드에 맞는 메모리 주소를 사용합니다. `vendor_boot`의 커널 cmdline은 CMA 128 MiB와 UART 진단 로그 설정을 담습니다.
- **LCD·터치**. 전원 공유 GPIO와 300 ms 기동 지연을 적용해 EDT 터치 장치가 냉간 부팅 시 등록됩니다. IRQ 전달 문제를 해결할 때까지 기존 드라이버의 17 ms 폴링을 사용합니다. 0번 DTB만 교체하고 나머지 DTB와 bootconfig를 보존합니다.
- **모듈 ABI**. 실제 배포 부트 커널은 TI 순정과 같습니다. 패널·PWM 모듈 빌드에는 실행 커널의 설정·심벌 ABI를 사용했습니다. `zsmalloc` 다음에 `zram`을 로드합니다.
- **SELinux·오디오**. 백라이트 밝기 권한과 세 sysfs 라벨을 반영했고, 장치의 SELinux Enforcing을 확인했습니다. 출력 전용 오디오 stub은 무음 경로입니다. USB 입력은 실제 장치의 프로파일을 탐색합니다. WM8960 아날로그 경로는 I2C 초기화에 실패했습니다.
- **사용자 설정**. 3버튼 내비게이션, 밀도 160 및 기본 앱 5개 비활성화는 기존 보드의 사용자 설정입니다. 재설치 대상 이미지와 별도로 적용합니다.
- **장치 복구**. F2FS encrypt 기능 복구와 A/B 시도 횟수 조정은 기존 장치의 일회용 복구 기록입니다. 일반 적용 스크립트는 이 작업을 수행하지 않습니다.
