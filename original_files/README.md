# TI 기준 파일

[파일별 보기](../docs/review-files.md)에서 Git에 저장한 원본 14개의 전문을 열 수 있습니다. `changed_files/`와 같은 상대 경로를 사용합니다.

U-Boot와 패널 파일의 기준은 고정된 TI 커밋입니다. vendor boot 헤더와 vendor 설정은 TI eMMC 배포 이미지에서 추출했습니다. 각 기준 이미지·소스의 SHA-256은 [검토 인덱스](../manifest/review-files.json)에 있습니다. 전체 후보 19개는 [로컬 재생성 절차](../docs/review-files.md#로컬-검토본-생성)로 확인할 수 있습니다.
