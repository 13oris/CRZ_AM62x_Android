# 변경 전 파일

[검토 파일 인덱스](../manifest/review-files.json)의 `modified` 항목 19개가 대상입니다. `changed_files/`와 같은 상대 경로를 사용합니다.

U-Boot와 패널 파일은 고정된 TI 커밋에서 가져옵니다. Android 이미지 쪽은 순정 DTB의 디컴파일 표현, vendor boot 헤더와 CPIO에서 뽑은 텍스트, 순정 `vendor_a`에서 추출한 설정입니다.

파일 전문을 보려면 [로컬 검토본 생성 안내](../docs/review-files.md)를 따르세요.
